# 📊 Stock Market Portfolio Risk & Return Analyzer

An interactive **Power BI dashboard** designed to analyze stock portfolio performance, investment risk, returns, and risk-adjusted performance.

The dashboard provides a comprehensive view of portfolio allocation, stock-level returns, volatility, beta, Sharpe ratio, maximum drawdown, cumulative returns, and performance under different investment scenarios.

---

## 🎯 Project Objective

The objective of this project is to develop an interactive portfolio analytics dashboard that helps investors and analysts understand:

- Portfolio performance
- Stock-wise returns
- Portfolio allocation
- Investment risk
- Annualized volatility
- Beta against NIFTY 50
- Sharpe ratio
- Maximum drawdown
- Risk vs. return relationship
- Portfolio performance under different scenarios
- Portfolio performance compared with the NIFTY 50

## 📈 Dashboard Features

### 1. Portfolio Allocation by Stock

A donut chart shows how the total portfolio investment is distributed across different stocks.

### 2. Total Return by Stock

A column chart compares the total return generated by each stock.

### 3. Risk vs Return Analysis

A scatter plot compares annualized volatility with total return to understand the relationship between risk and performance.

### 4. Portfolio vs NIFTY 50 Cumulative Return

A line chart compares portfolio cumulative performance against the NIFTY 50 benchmark.

### 5. Risk-Adjusted Stock Performance

A horizontal bar chart compares the Sharpe Ratio of individual stocks.

### 6. Portfolio Return Under Different Scenarios

The dashboard evaluates portfolio performance under different investment strategies:

- Base Portfolio
- Tech +10% (TCS)
- Defensive Tilt (Sun Pharma)
- Equal Weight

## 📐 Key Financial Metrics

### Portfolio Return

Measures the overall percentage gain or loss generated by the portfolio.

### Annualized Volatility

Measures the annualized variability of portfolio returns and represents investment risk.

### Beta

Measures the sensitivity of portfolio returns relative to the NIFTY 50 benchmark.

### Sharpe Ratio

Measures risk-adjusted performance by comparing portfolio returns with the level of risk taken.

### Maximum Drawdown

Measures the largest decline from a portfolio's peak value to its subsequent lowest point.
